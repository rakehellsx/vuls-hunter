# AI-Vuln Scanner (Vuls-Hunter) 漏洞挖掘平台原型系统

Vuls-Hunter 是一款基于 **Vue3**、**Vite**、**Tailwind CSS** 与 **TypeScript** 打造的 AI 驱动的漏洞挖掘与安全审计平台原型系统。本系统秉持“智感雅致美学 (Intelligent Elegance)”设计风格，完美还原并深度实现了现代自主网络推理系统（Cyber Reasoning Systems, CRS）的核心业务流。

---

## 1. 系统架构设计 (System Architecture)

系统采用**神经符号（Neuro-Symbolic）混合架构**作为核心理念，通过多智能体（Multi-Agent）协同调度，实现从代码解析、数据流追踪、大模型语义审计到自动修复的完整闭环。

```
+-------------------------------------------------------------------+
|                        WEB 端用户交互界面 (Vue3)                   |
|  - 概览统计  - 智能对话  - 快速检测  - 项目管理  - 规则管理  - 日志审计   |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                 多智能体协同层 (Multi-Agent Orchestrator)          |
|  +------------------+  +------------------+  +-----------------+  |
|  |  威胁建模智能体  |  |  审计规划智能体  |  |  补丁生成智能体 |  |
|  +------------------+  +------------------+  +-----------------+  |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                     神经符号混合引擎层 (Hybrid Engine)             |
|  +---------------------------------+  +-------------------------+ |
|  |       符号分析 (Symbolic)       |  |  神经网络 (Neural / LLM) | |
|  |  - Tree-sitter AST & Call Graph |  |  - 语义上下文理解       | |
|  |  - 静态数据流可达性分析         |  |  - 业务逻辑意图推理     | |
|  +---------------------------------+  +-------------------------+ |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                    动态验证与执行层 (Dynamic Sandbox)              |
|  - 隔离编译环境  - 动态调试器 (GDB)  - 流量重放与 PoC 触发         |
+-------------------------------------------------------------------+
```

1. **编译前端与符号引擎**：利用 `tree-sitter` 快速解析源码生成抽象语法树（AST），构建跨文件的全局调用图（Call Graph）。通过符号分析进行静态数据流追踪，标记出物理上可达的路径，作为 AI 智能体的导航地图。
2. **神经网络语义推理**：调用安全大模型（如 360 安全大模型、DeepSeek-R1 等），沿着符号引擎标记出的可达路径进行语义推理，理解业务逻辑意图，精准捕获越权、命令注入、提示词注入等复杂漏洞。
3. **多智能体协同工作流**：
   * **威胁建模智能体**：识别高价值资产、入口点（API）和安全控制机制。
   * **审计规划智能体**：分段读取代码上下文，提出潜在漏洞假设。
   * **验证智能体**：在隔离沙箱中自动编写并执行 PoC/Exploit 载荷，通过崩溃复现彻底消除幻觉误报。
   * **补丁生成智能体**：分析漏洞根因，生成安全修复补丁并运行回归测试。

## 2. 各模块功能说明 (Core Modules)

### 2.1 概览统计 (Overview)
提供全局安全态势看板，包含活动未解决漏洞评级（Critical、High、Medium、Low）、AI 自动修复率统计、安全规则库分类占比、以及最新审计项目列表。支持一键跳转智能对话或快速检测。

### 2.2 智能对话 (Chat Agent)
**参考 Manus 极简高雅风格设计的左右结构交互面板**：
* **左侧会话历史列表**：支持多会话管理、新建会话、删除会话以及流畅的会话切换。
* **右侧对话流**：支持用户通过自然语言下达漏洞挖掘引导指令。AI 智能体在理解意图后，会实时输出审计推导依据，并提供智能交互卡片（如“一键应用修复补丁”、“跳转查看项目详情”），实现与全局状态的深度打通。

### 2.3 快速检测 (Quick Scan)
提供免绑定仓库的轻量级单文件/函数检测。支持 Python、Java、Go、C/C++、JavaScript 等语言，内置经典 SQL 注入、系统命令执行等高危漏洞范例。AI 引擎可在秒级输出分析终端日志、漏洞简报以及 AI 智能修复补丁对比。

### 2.4 项目管理 (Projects)
管理绑定的企业代码仓库。支持关联 GitHub/GitLab 仓库、配置审计分支。
* **深度扫描日志**：实时模拟展示 AST 构建、调用图解析、SCA 依赖分析、指向性分析、大模型推理及误报降噪过滤的多步骤运行日志。
* **漏洞详情与数据流**：以可视化步骤条形式展示静态数据流（污点）追踪图，清晰呈现污点从 Source 到 Sink 的传播路径，并提供 AI 修复补丁对比与“一键修复”功能。

### 2.5 规则管理 (Rules)
管理与自定义安全检测规则。平台规则库兼容 CWE、OWASP Top 10、CERT 标准，支持自定义规则的在线创建、严重等级划分、规则类型占比统计，并支持利用大模型对自定义规则进行智能编译下发。

### 2.6 报告管理 (Reports)
安全审计完成后自动生成深度安全审计报告。展示报告 ID、关联项目、审计时间、漏洞评级及合规评级（如通过 A+ / 整改中 D-）。支持一键导出为 PDF、Markdown 及在线预览。

### 2.7 引擎管理 (Engine)
监控与调配底层 AI 漏洞挖掘引擎内核。支持 Tree-sitter 编译前端、Symbolic 符号分析引擎、AI 大模型推理内核的状态监控与热重启。提供 GPU 算力负载、内存占用及 RAG 知识库命中率的实时性能大屏。

### 2.8 日志审计 (Audit Logs)
记录平台所有的操作日志、引擎调用状态以及策略变更，支持完整的安全合规追踪，防止内部越权或敏感配置篡改。

### 2.9 系统管理 (Settings / Integrations)
管理第三方工具集成生态，支持一键对接 Git 仓库自动同步、Jenkins CI/CD 流水线集成、Jira/禅道缺陷同步、IDE 插件端（VS Code / IntelliJ）实时预警、以及钉钉/企微消息推送。

## 3. 快速开始 (Quick Start)

### 3.1 环境要求
* Node.js >= 18.0.0
* pnpm >= 8.0.0

### 3.2 安装依赖
```bash
pnpm install
```

### 3.3 启动开发服务器
```bash
pnpm run dev
```
打开浏览器访问 `http://localhost:3000` 即可体验。

### 3.4 构建生产环境
```bash
pnpm run build
pnpm start
```
